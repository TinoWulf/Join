# Join - Task Management Board
Live demo / test: https://join.rucel-tsafack.com/index.html 
A modern, collaborative task management application built with vanilla JavaScript, Firebase, and responsive CSS. Organize tasks across multiple categories (To Do, In Progress, Await Review, Done) with drag-and-drop functionality, subtask tracking, and team member assignments.

## Features

- **Drag & Drop Task Management** - Easily move tasks between different status categories
- **Task Categories** - Organize tasks as: To Do, In Progress, Await Review, Done
- **Subtask Tracking** - Break down tasks into subtasks with completion progress
- **Team Assignment** - Assign multiple team members to tasks with color-coded initials
- **Priority Levels** - Mark tasks with different priority grades (Low, Medium, High, Urgent)
- **Task Types** - Support for User Stories, Bugs, Features, Tasks, and Improvements
- **Real-time Database** - Firebase integration for data persistence and synchronization
- **Responsive Design** - Works seamlessly on desktop and mobile devices
- **User Authentication** - Secure login system with localStorage support
- **Search & Filter** - Find tasks quickly with built-in search functionality
- **Task Details Modal** - View and edit task information in an intuitive modal interface

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Database:** Firebase Realtime Database
- **Version Control:** Git

### Creating a Task
1. Click the "Add Task" button
2. Fill in task details (title, description, type, priority)
3. Assign team members
4. Add subtasks if needed
5. Click "Create Task"

### Managing Tasks
- **Drag & Drop:** Click and drag tasks between columns to change their status
- **View Details:** Click on a task card to see full details
- **Edit Task:** Click the edit icon to modify task information
- **Delete Task:** Click the delete icon to remove a task
- **Track Progress:** Monitor subtask completion with the progress bar

### Task Properties
- **Type:** User Story, Bug, Feature, Task, Improvement
- **Priority:** Low, Medium, High, Urgent
- **Status:** To Do, In Progress, Await Review, Done
- **Assigned To:** Multiple team members with color-coded initials
- **Subtasks:** Track individual task components
